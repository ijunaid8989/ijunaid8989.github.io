# Company Logos

Place company logo images in this directory. The logos should be:

- **Format**: PNG or SVG (preferred)
- **Size**: Recommended 200-300px width, transparent background preferred
- **Naming**: Use the following filenames:

  - `yolo.png` - Yolo logo
  - `nectarine-credit.png` - Nectarine Credit logo
  - `helium-health.png` - Helium Health logo
  - `greyscout.png` - GreyScout logo
  - `truely.png` - Truely logo
  - `whippy.png` - Whippy logo
  - `catalx.png` - Catalx logo

If a logo is not found, the company name will be displayed as text instead.

## How to get logos:

1. Visit each company's website
2. Look for their press/media kit or brand resources
3. Download the logo in PNG or SVG format
4. Place it in this directory with the correct filename
